# AI-AGENT
Xây dựng một AI Agent có khả năng đọc CV, phân tích JD, đánh giá mức độ phù hợp và đề xuất những nội dung cần cải thiện trong CV.
1.Các chức năng chính 
a.Mô tả công việc Fetch
- Nhận đường dẫn JD hoặc nội dung JD.
- Thu thập thông tin tuyển dụng.
- Trích xuất yêu cầu kỹ năng, kinh nghiệm, trình độ.
b.Read CV PDF
- Đọc file CV PDF.
- Trích xuất thông tin cá nhân, học vấn.
- Trích xuất kỹ năng, kinh nghiệm và dự án.
- Chuyển nội dung thành dữ liệu có cấu trúc.
c.Điểm đánh giá
- So sánh CV với JD.
- Đánh giá kỹ năng chuyên môn.
- Đánh giá kinh nghiệm và dự án.
- Tính điểm phù hợp.
d. AI Agent
- Tự quyết định thứ tự thực hiện công việc.
- Tự gọi các Tool cần thiết.
- Xử lý khi Tool gặp lỗi.
- Tổng hợp kết quả từ nhiều Tool.
e.Generate Report
- Điểm phù hợp tổng thể.
- Những kỹ năng còn thiếu.
- Điểm mạnh của CV.
- Đề xuất chỉnh sửa CV.
